How to update this calendar

  • Open this file in a text editor and find the TEAM_MEMBERS array to add/remove people and change their colors.
  • Add OOO periods in EVENTS: { type: 'ooo', person: 'Name', start: '2026-MM-DD', end: '2026-MM-DD' }
  • Add birthdays: { type: 'birthday', person: 'Name', date: '2026-MM-DD' }
  • Add anniversaries: { type: 'anniversary', person: 'Name', date: '2026-MM-DD', years: 3 }
  • Add holidays: { type: 'holiday', name: 'Holiday Name', date: '2026-MM-DD' }
