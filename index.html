How to update this calendar

  • Find TEAM_MEMBERS near the top of this file to add/remove people or change colors.
  • Add OOO: { type: 'ooo', person: 'Name', start: 'YYYY-MM-DD', end: 'YYYY-MM-DD' }
  • Add birthday: { type: 'birthday', person: 'Name', date: 'YYYY-MM-DD' }
  • Add anniversary: { type: 'anniversary', person: 'Name', date: 'YYYY-MM-DD', years: N }
  • Add holiday: { type: 'holiday', name: 'Holiday Name', date: 'YYYY-MM-DD' }
